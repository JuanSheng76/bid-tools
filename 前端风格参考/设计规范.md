# 清爽政企蓝前端设计规范

> 适用范围：招投标管理、政企业务后台、运营工作台、项目与任务系统  
> 视觉关键词：清爽、专业、可信、高信息密度、层次清晰、克制动态  
> 当前版本：V2 · Light Enterprise UI

---

## 1. 设计原则

### 1.1 明亮工作区，深蓝品牌锚点

- 主工作区采用浅灰蓝背景 `#f3f6fa`，内容容器以白色为主。
- 深色只用于固定侧栏、登录页品牌区等有限区域。
- 不使用大面积纯白铺底，通过浅灰背景、白色卡片和细边框建立层次。
- 不依赖厚重阴影区分所有层级；阴影仅用于悬浮、弹窗和登录卡片。

### 1.2 蓝色用于操作，蓝绿色用于成功

- 政企蓝是主品牌色，用于当前导航、主按钮、链接和焦点状态。
- 蓝绿色只用于成功、完成、正常运行等语义。
- 黄色用于临期和待确认，红色用于风险、失败和删除。
- 同一页面只保留一个高权重主按钮。

### 1.3 高密度但保持清晰

- 默认字号以 10–14 px 为主，依靠对齐、间距与分组提升可读性。
- 卡片间距为 11–16 px，卡片内部间距为 14–20 px。
- 表格首列承载主实体名称，状态、金额、截止日期独立成列。
- 首屏优先展示指标、待处理事项、风险提醒和业务入口。

### 1.4 动效用于反馈和层次

- 工作台动效以 hover、focus、loading 和轻微入场为主。
- 登录页可使用缓慢光晕、网格漂移、状态呼吸灯和卡片入场。
- 循环动画应缓慢、低对比，不影响文字阅读。
- 必须支持 `prefers-reduced-motion: reduce`。

## 2. 设计令牌

可直接复用同目录下的 `tokens.css`。

### 2.1 基础颜色

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--ops-bg` | `#f3f6fa` | 页面背景 |
| `--ops-sidebar` | `#102a46` | 固定侧栏 |
| `--ops-panel` | `#ffffff` | 卡片、弹窗 |
| `--ops-panel-raised` | `#f6f8fb` | 二级容器、次按钮 |
| `--ops-input` | `#fbfcfe` | 输入控件 |
| `--ops-text` | `#182638` | 主文字 |
| `--ops-text-soft` | `#4f6278` | 次级文字 |
| `--ops-muted` | `#728399` | 辅助说明 |
| `--ops-faint` | `#9aa8b8` | 弱提示 |
| `--ops-line` | `#dce4ed` | 边框与分隔线 |
| `--ops-line-soft` | `#edf1f5` | 表格行分隔线 |

### 2.2 语义颜色

| 语义 | 色值 | 用途 |
|---|---|---|
| Primary | `#2563a8` | 主操作、链接、当前状态 |
| Primary Hover | `#1d508b` | 主操作悬停 |
| Success | `#168b78` | 正常、完成、中标 |
| Info | `#3478c5` | 信息、进行中 |
| Warning | `#c78217` | 临期、待确认 |
| Danger | `#d0525d` | 风险、失败、删除 |

语义色背景使用对应颜色的 5%–9% 浅色，边框使用 18%–28% 混合色，文字使用深一档色值。

### 2.3 字体

```css
font-family: "DM Sans", "Noto Sans SC", sans-serif;
```

- 中文使用 Noto Sans SC。
- 数字、金额和英文使用 DM Sans。
- 页面默认字号：14 px。
- 页面标题：25 px / 600。
- 指标数字：26–30 px / 600。
- 卡片标题：13 px / 600。
- 表格正文：11–12 px。
- 辅助文字：9–11 px。
- 导航分组使用大写感字距 `0.18em`。

### 2.4 圆角与阴影

| 元素 | 圆角 |
|---|---:|
| 主卡片 | 11 px |
| 登录卡片 | 18 px |
| 弹窗 | 13 px |
| 按钮 | 8 px |
| 输入框 | 7–10 px |
| 导航项 | 9 px |
| 状态标签 | 999 px |

```css
--ops-shadow-sm: 0 1px 2px rgba(31, 50, 73, .04);
--ops-shadow-md: 0 8px 24px rgba(31, 50, 73, .07);
--ops-shadow-lg: 0 22px 60px rgba(31, 50, 73, .16);
```

- 标准卡片只使用细边框和最轻阴影。
- hover 可提高一档阴影，不做明显上浮。
- 登录卡片、菜单和弹窗可使用中高层阴影。

### 2.5 间距

基础间距序列：

```text
4 / 6 / 8 / 10 / 12 / 14 / 16 / 20 / 24 / 28 / 30 / 32
```

关键尺寸：

- 侧栏宽度：226 px。
- 顶栏高度：74 px。
- 页面左右边距：30 px。
- 卡片间距：11–16 px。
- 卡片标题栏：53 px。
- 表格单元格：12 px 14 px。
- 登录表单卡片：宽 430 px，内边距 38 px。

## 3. 页面结构

### 3.1 应用外壳

```text
┌───────────┬──────────────────────────────────────────┐
│ 品牌区域   │ 顶栏 / 页面上下文 / 用户信息              │
│           ├──────────────────────────────────────────┤
│ 主导航     │ 页面标题 + 说明                 主操作    │
│           ├──────────────────────────────────────────┤
│ 次导航     │ 指标卡片                                 │
│           ├────────────────────────┬─────────────────┤
│           │ 主数据区               │ 提醒 / 辅助区    │
│           │                        │                 │
└───────────┴────────────────────────┴─────────────────┘
```

- 使用 `226px + 1fr` 两列布局。
- 深蓝侧栏固定在视口左侧。
- 主内容最小宽度建议 950 px。
- 主数据与辅助信息常用 `1.55fr / .85fr` 比例。
- 页面标题区右侧放置 1–3 个页面级操作。

### 3.2 指标区

- 单行建议 4–5 个指标。
- 数值是视觉焦点，说明使用低对比文字。
- 卡片背景保持白色或极浅蓝灰。
- 红色数值只用于确实需要立即处理的异常。
- 不使用多色顶边和彩色大面积背景。

### 3.3 登录页

登录页使用左右双栏：

- 左侧为深蓝品牌区，包含品牌、价值主张和 3 项核心能力。
- 右侧为浅灰渐变背景和白色悬浮登录卡片。
- 左侧可使用 CSS 光晕、网格、轨道和信号节点建立层次。
- 右侧可使用低透明圆环、微光点和卡片入场。
- 表单必须始终保持最高对比度，不让背景动态穿过输入区域。

## 4. 组件规范

### 4.1 侧边导航

- 默认文字为半透明浅蓝灰。
- hover 使用 6% 白色透明背景。
- active 使用蓝色半透明渐变，并增加 2 px 左侧指示线。
- 图标统一 16 px、线性风格、相同线宽。
- 导航分组使用低对比度大写感标签。

### 4.2 卡片

```html
<section class="ops-card">
  <header class="ops-card__head">
    <h3>卡片标题</h3>
    <span class="ops-caption">补充信息</span>
  </header>
  <div class="ops-card__body">...</div>
</section>
```

- 白色背景、浅灰蓝边框。
- 标题栏与正文之间使用细分隔线。
- 并列卡片保持相同高度。
- 标准卡片不使用大面积渐变。

### 4.3 数据表格

- 表头背景使用 `#f7f9fc`。
- 表头 9–10 px，正文 11–12 px。
- 行之间只使用浅色细分隔线。
- hover 使用 `#f6f9fc`，不改变文字颜色。
- 避免每行放置多个高饱和按钮。

### 4.4 状态标签

```text
蓝绿色：正常、完成、中标
蓝色：信息、进行中、已报名
黄色：待确认、临期、谨慎
红色：失败、逾期、高风险
灰色：来源、分类、已忽略
```

状态标签必须同时使用颜色与文字，不能只依赖颜色表达。

### 4.5 按钮

- 主按钮：政企蓝实心、白色文字、字重 700。
- 次按钮：白色背景、浅灰蓝边框。
- 成功按钮：蓝绿色实心，仅用于明确成功类操作。
- 危险按钮：默认白底红字，hover 才转为红色实心。
- 同一区域不超过一个主按钮。

### 4.6 表单

- label 使用 10–12 px 深灰蓝。
- 输入框采用极浅灰背景和浅灰蓝边框。
- focus 使用蓝色边框与 9% 透明蓝色外环。
- textarea 最小高度 74 px。
- 复杂表单采用两列，长文本字段占满整行。

### 4.7 弹窗与反馈

- 弹窗背景为白色，遮罩使用深蓝灰 48% 透明度。
- 成功 toast 使用蓝绿色左边线。
- 错误 toast 使用红色左边线。
- loading 使用小型 spinner 和明确说明。
- 空状态使用线性图标和一条下一步提示。

## 5. 登录页动态规范

### 5.1 可使用的动态

- 12–18 秒循环的低透明径向光晕。
- 20 秒以上的背景网格缓慢位移。
- 2–4 秒循环的状态呼吸灯。
- 600–800 ms 的内容与卡片入场。
- 输入框 focus 上移 1 px。
- 主按钮 hover 可使用一次性横向流光。

### 5.2 动态强度

- 循环动画位移不超过容器尺寸的 10%。
- 光晕透明度建议低于 35%。
- 卡片入场位移不超过 20 px。
- 不使用快速闪烁、抖动、连续缩放或鼠标跟随。
- 动态元素不得承载必须阅读的信息。

### 5.3 无障碍

```css
@media (prefers-reduced-motion: reduce) {
  .animated-element {
    animation: none !important;
    transition-duration: .01ms !important;
  }
}
```

装饰元素添加 `aria-hidden="true"`，输入框必须有可见 label，错误信息使用 `role="alert"`。

## 6. 响应式策略

- 1440 px 以上：完整四至五列指标与双栏业务区。
- 1180–1439 px：保持布局，缩小页面边距。
- 980–1179 px：侧栏缩窄，指标改为两列。
- 登录页低于 900 px 时可隐藏品牌区，保留独立登录卡片。
- 手机端表格应改为卡片列表，不直接压缩桌面表格。

---

## 7. 复用步骤

1. 复制 `tokens.css`。
2. 建立页面外壳、侧栏、顶栏和内容区。
3. 复用卡片、表格、按钮、标签和表单组件。
4. 替换品牌名和真实业务文案。
5. 根据业务增加指标数量，不新增装饰色。
6. 登录页动态保持低对比，并提供 reduced-motion 回退。
7. 使用真实长文本、空状态、异常状态和密集表格验证。

## 9. 反例清单

避免：

- 主工作区使用大面积深色或纯白。
- 同时使用紫色、青色、橙色等多个品牌强调色。
- 每张指标卡使用不同彩色顶边。
- 使用厚重阴影区分所有层级。
- 大量圆角超过 16 px 的普通容器。
- 页面上同时出现多个蓝色主按钮。
- 只有颜色、没有文字的状态提示。
- 登录页使用快速闪烁、粒子喷射或强鼠标跟随。
- 动画覆盖表单内容或影响输入。
- 使用 lorem ipsum 或无关占位数据。
